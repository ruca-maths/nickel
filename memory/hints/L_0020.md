# L_0020（stratifiable だが CP 開外基を持たない点がある空間の存在）の研究方針

作成: Claude。研究責任者（ユーザー）が 2026-11-26 にチャットで追加を承認した。全体の方針は memory/hints/L_0009.md を参照。

## 方針
- L_0020 は Chen–Wang（arXiv 1809.03763v2）の空間 (Y, τ) を形式化して示す。
- 「Ceder の問題そのものなので分解できない」として止まらないこと。構成は具体的で、示すべきことは個々の命題の積み重ねである。
- 論文本文: `work/reference/chen-wang-1809.03763v2.txt`（親機のみ）。
- 命題 9.5 は「y ∈ H₀ の**任意の**開近傍基 V_y は CP でない」という形である（本文 2446 行付近）。よって「∃ y, ¬HasCPOuterBase y」は命題 9.5 にあたる。

## 分解の第一歩（案）
1. 第2節の対象（Q、Δ-順序、区間族）を定義モジュールにする。一度に全部を作らなくてよい。
2. Y の定義ができたら、通常の帰着で L_0020 を次の2つの子に分ける。
   - 子: `Defs.D_k.Y` は stratifiable（Theorem 1.a、第7節）
   - 子: `∃ y : Defs.D_k.Y, ¬ Defs.D_0001.HasCPOuterBase y`（命題 9.5）
3. Y の定義がまだ無い段階では、第2〜3節の部品の補題（Proposition 2.x, 3.x）から立てる。
4. 1セッションでは部品を1つ（定義1つと補題数個）進めればよい。
