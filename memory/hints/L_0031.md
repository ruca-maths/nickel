# L_0031（Chen–Wang の Y：stratifiable かつ clopen-Gδ 点で CP 外基なし）の研究方針

作成: Claude。研究責任者（ユーザー）が 2026-11-27 にチャットで追加を承認した。全体方針は memory/hints/L_0009.md, L_0020.md を参照。

## 方針
- L_0031 は ∃Y の命題なので、Y が Defs に定義されるまでは健全な帰着を立てられない。それは想定内であり、gave_up の理由にしないこと。
- decompose の1セッションでは「Y に向けて次の定義モジュールを1つ（＋必要なら部品の補題を子として数個）」足せば成果とする。
  - 既存: D_0002〜D_0011（§2〜3.1）、D_0012（Construction 3.2）、D_0013（Prop 3.2.1 の前提）。
  - 次: 論文 §4〜6 の構成を順に。最終目標は `Defs.D_k.Y` と点 `y`、開閉集合の列 `W n` の定義。
- Y・y・W が定義できたら、L_0031 を次の3つの子に分解する:
  1. `IsStratifiable Defs.D_k.Y`（Theorem 1.a、§7）
  2. `(∀ n, IsOpen (W n) ∧ IsClosed (W n) ∧ y ∈ W n) ∧ ⋂ n, W n = {y}`（ρ が離散位相の積であることから。要確認: 論文は成分の距離空間が 0 次元としか書いていない）
  3. `¬ Defs.D_0001.HasCPOuterBase y`（Prop 9.5、本文 2446 行付近）
- 子 2 が論文から直ちに出ない場合は、その旨を具体的に記録すること。
