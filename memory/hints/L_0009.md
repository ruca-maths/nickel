## 論文の骨格
- **Theorem 1.b（M₁ でない）の証明は短い。** σ-closure-preserving な基 𝓑 = ⋃ 𝓑ᵢ があると仮定する。B(i,y) = {B ∩ g(i,y) : y ∈ B ∈ 𝓑ᵢ} とおくと、B(y) = ⋃ᵢ B(i,y) は点 y の closure-preserving な外基になる。これは命題 9.5 と矛盾する。
  - 命題 9.5: ある点 y の近傍族 V_y は closure-preserving でない。
- **関連する既知の結果（Ito 1985, Mizokami）:**
  - M₃ 空間で、各点が closure-preserving な外基（outer base）を持てば M₁。
  - 逆に、M₁ 空間の各点は closure-preserving な外基を持つ。
  - よって M₃ = M₁ 問題は、「stratifiable 空間の各点が closure-preserving な外基を持つか」と同値。
- **Heath–Junnila（1981）:** 任意の stratifiable 空間は、ある M₁ 空間の perfect retract になる。

## 推奨する分解（Architect 向け）
1. **定義モジュールを作る。** 点 x の「closure-preserving な外基」を表す述語 `HasCPOuterBase`（X と x について）。
   - 「外基」の正確な定義は、Ito / Mizokami の用法に合わせること。目安は「x を含む開集合の族で、x の任意の開近傍 U に対して族の要素 V ⊆ U がある」。
   - 第9節の B(y) の作り方と食い違わないよう、本文を確認すること。
   - 定義を誤ると子1が偽になる。その場合は Red Team の反証で分かる。
2. **`negate: true` の帰着で、¬Tinf を次の3つの子に分ける。**
   - **子1（一般論）:** `∀ (X : Type) [TopologicalSpace X], MSpace.IsM1 X → ∀ x : X, HasCPOuterBase x`
     - Theorem 1.b の証明の前半にあたる。構成に依存しない、独立した補題である。
     - ここが偽なら、論文の Theorem 1.b の論法が崩れていることになる（最初に確かめる価値がある）。
   - **子2:** 反例空間 `Defs.D_xxxx.Y`（`Y : Type`）が `MSpace.IsM3`。
     - 既に証明済みの L_0004（M₃ ⇔ stratifiable）を使えば、「g-関数 / stratification を持つ T₁ 空間」を示せば足りる。
   - **子3:** `∃ y : Defs.D_xxxx.Y, ¬ HasCPOuterBase y`（命題 9.5 の形）。
   - 帰着の本体は易しい。Tinf を Y に適用して IsM1 Y を得て、子1で HasCPOuterBase y を得て、子3と矛盾させる。
3. **子2・子3は巨大なので、論文の節に沿ってさらに分解する。**
   - 第2節: Q の Δ-順序と区間族
   - 第3節: H, G の構成
   - 第4〜5節: L_n 被覆
   - 第6節: 近傍の穴
   - 第7節: (Y, τ) と g-関数
   - 各命題・主張（Proposition 2.1, 3.1, … Claim 5.8, Fact 6.9, …）を 1 補題ずつ立てる。
   - 構成要素（集合・族・関数）は定義モジュールに置く。
4. **論文の主張が Lean で証明できない（偽と分かる）箇所が見つかったら、その補題の反証を残す。**
   - これは「プレプリントの穴」の発見であり、重要な成果である。
   - `release --note` に、どの命題のどの段階かを具体的に書くこと。
