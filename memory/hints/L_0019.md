# L_0019（M₁ ⇒ 各点に CP な開外基）の研究方針

作成: Claude（研究責任者の指示「Tinf の研究を継続して解決」を受けて、文献を確認して作成）。2026-11-26

## 文献で分かったこと
- **これは易しい補題ではない。**
  - Mizokami の 2003 年のサーベイ（arXiv math/0312457）は、未解決問題 (P4)「M₁ 空間の任意の点は CP な開近傍基を持つか」として挙げている。
  - その後、Lin–Lin（arXiv 1302.4200）によると、T. Mizokami, *On closed subsets of M₁-spaces*, Topology Appl. 141 (2004) 197–206 がこれを肯定的に解いた。
  - この論文の本文は手元にない。
- **Chen–Wang の Theorem 1.b は1行で済ませているが、そのままでは不完全。**
  - そこでは B(i,y) = {B ∩ g(i,y) : y ∈ B ∈ 𝓑ᵢ} とおいている。
  - 開集合 g との共通部分を取ると、CP 性は一般に保たれない。
  - これまでの Architect と Prover が指摘してきた「境界問題 y ∈ ∂O_n」は正しい障害である。
- **使ってよい事実（Mizokami のサーベイが紹介する Ito の手法）:**
  - M₃ 空間の閉集合 M は、CP な閉近傍基 𝓑 を持つ。
  - さらに、各 D_n が離散かつ閉である稠密集合 D = ⋃ D_n で、各 B ∈ 𝓑 について B = cl(B ∩ D) となるものが取れる。
  - 各点 p ∈ D_n ∩ B を p の開基で膨らませると、CP な開近傍基ができる。
  - M₁ では σ-CP 基があるので、この膨らませ方をさらに制御できるはず（Mizokami 2004 の方針と推測される。未確認）。

## 推奨
1. **閉近傍版を先に切り出す。**
   - 子A:「M₁（または M₃）空間の各点は、CP な閉近傍基を持つ」。これは易しい側である。
   - 子B:「CP な閉近傍基と σ-CP 基から、CP な開外基を作る」。Ito の稠密集合 D による膨らませ方を使う。
2. 子B が難しければ、さらに分ける。
   - 「M₃ 空間は σ-離散な閉集合族からなる稠密な網を持つ」のような、既知の部品に分けること。
3. **どうしても示せない場合も、成果として記録する。**
   - その場合は「Chen–Wang の Theorem 1.b は Mizokami 2004 に依存し、論文中の1行の論証は不完全」と明記した note を残す。
   - これはプレプリントの穴の指摘として、研究上の成果になる。
