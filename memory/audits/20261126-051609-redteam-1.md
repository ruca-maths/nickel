# 仕様監査報告: Targets/Defs.lean, Targets/Goals.lean（redteam-1）

結論: **致命的な欠陥は見つからなかった。** 定義はどれも Ceder (1961)、Borges (1966)、
Gruenhage のハンドブックの標準的な定義と一致するか、同値な形になっている。
自明に真や偽になる穴も見つからなかった。以下の軽微な注意点・推奨点は、人間のレビュー時の確認用に挙げる。

## 1. 分離公理
* Mathlib の `T3Space X` は `T0Space X` と `RegularSpace X` を合わせたもの（`Separation/Regular.lean:454` で確認）。
  正則と T₀ がそろえば T₁（実際には T₂）が出るので、Ceder の「正則 T₁」と一致する。
  `RegularSpace` は Mathlib では T₁ を含まない。それでも T₀ と組み合わせるので問題はない。
* `IsStratifiable` は T₁ と stratification を課しており、これは Borges の定義どおり。
  stratification があれば正則性が出る（x ∉ H なら、ある n で x ∉ cl G(n,H) となり、
  G(n,H) と X∖cl G(n,H) が x と H を分離する）。したがって T2a（M₃ ⇔ stratifiable）の
  両辺で分離公理の強さがずれる心配はない。
* `NormalSpace` は Mathlib では T₁ を含まない（`Regular.lean:511`）。T2c では仮定に T₁ があるので
  影響はない。ただし `IsPerfectlyNormal` 自体は T₁ を含まない「完全正規」なので、
  T₁ を含む流儀の文献と照らし合わせるときは注意が必要。
  **推奨:** Mathlib には `PerfectlyNormalSpace`（`Separation/GDelta.lean:65`、`NormalSpace` を拡張し
  closed ⇒ Gδ を加えたもの）がある。自前の定義と中身は同じなので、将来 Mathlib の補題を使うために
  `IsPerfectlyNormal X ↔ PerfectlyNormalSpace X` を補題として用意しておくとよい。
* `ParacompactSpace` は Mathlib では Hausdorff 性を含まない。T2b は T₂ を含まない形の主張で、
  これは T₂ を含む主張より弱いか同等なので正しい。T₂ は T2a の経路から別途得られる。

## 2. 族の性質
* `ClosurePreserving` は **任意の** 部分族 𝓖 ⊆ 𝓕 について `closure (⋃₀ 𝓖) = ⋃₀ (closure '' 𝓖)` を要求しており、
  Ceder の定義どおり（有限部分族版ではない）。族を `Set (Set X)` で表しているので重複は消えるが、
  closure-preserving かどうかは重複に影響されないので問題ない。
* `Cushioned` も任意の部分族 𝓠 ⊆ 𝓟 について `cl(⋃ P₁) ⊆ ⋃ P₂` を要求しており、Ceder の定義どおり。
* σ-版は `𝓑 = ⋃ n, 𝓑' n`（ℕ で添字付けた可算和）。有限和や空族の場合も、空族を並べれば表せる。
* `IsQuasiBase` は `x ∈ int B ⊆ B ⊆ U` を要求しており、Ceder の定義どおり。
* `IsPairBase` は P₁ が開で P₁ ⊆ P₂、P₂ は任意の集合で、`x ∈ P₁` かつ `P₂ ⊆ U` を要求しており、Ceder の定義どおり。
* `IsTopologicalBasis` は Mathlib の構造体で、各元が開集合であることが含意される。
  したがって「開基」と一致する。

## 3. stratification
* 閉集合版（Gruenhage 形）で、単調減少性を課していない。G'(n,H) = ⋂_{k≤n} G(k,H) と取り直せば、
  開性・H ⊆ G'・単調性・⋂ cl = H がすべて保たれるので、単調減少性を課す版と同値。
* 条件を閉集合 H, K に限っているので、閉でない集合での値は自由になる。これは意図どおりで問題ない。
* Borges の原定義は開集合版（U ↦ (Uₙ)、cl Uₙ ⊆ U、⋃ Uₙ = U、U ⊆ V ⇒ Uₙ ⊆ Vₙ）。
  補集合を取ると両者は同値になる。ただしこの同値性は Lean では未証明。
  T2a を Borges の原論文に沿って証明するなら、この変換を補題として切り出すとよい。

## 4. 目標命題
* T1a: 局所有限族の任意の部分族は局所有限で、局所有限族では閉包と和が交換するので真。分離公理も不要。
* T1b: 開基は quasi-base なので、ほぼ自明。
* T1c: quasi-base B に対して (int B, cl B) を取れば cushioned になる。ただし cl B ⊆ U を確保するために
  正則性を使う必要がある。真。
* T2a: Borges (1966) の定理（M₃ ⇔ stratifiable）そのもの。
* T2b・T2c: Borges の結果。
* T2d: Nagata–Smirnov / Bing により σ-局所有限な開基がとれ、T1a と組み合わせれば真。
* T3: Gruenhage (1976)、Junnila (1978) の M₃ ⇒ M₂。
* Tinf: `∀ X : Type, IsM3 X → IsM1 X`。否定は `∃ X : Type, IsM3 X ∧ ¬IsM1 X` で、
  「M₃ だが M₁ でない空間がある」という主張を正しく表している。

## 5. 宇宙・自明性
* Goals は `X : Type`（宇宙 0）に限っている。`Type` は冪集合などで閉じているので、
  通常の位相空間論で現れる空間はすべて `Type` に入る。よって数学的な制限にはならないと判断する。
  厳密には、宇宙 1 以上にしか存在しない反例があれば Tinf（宇宙 0 版）と一般版がずれうる。
  しかし M₃ ⇒ M₁ の反例の濃度は位相の構成から抑えられると考えられ、実質的な問題はない。
* 空間が空のとき: `T3Space` は成立し、∅ は位相基底で closure-preserving なので、IsM1・IsM2・IsM3 はすべて真になる。
  空間が空でも非空でも、どちらかの側が自明に成立・不成立になる穴は見当たらない。
* 定義はどれも `Prop` 値で、型クラスのインスタンスの衝突（同じ X に別の位相が入るなど）はない。

## 6. 推奨事項（いずれも任意）
1. `IsPerfectlyNormal` と Mathlib の `PerfectlyNormalSpace` の同値性を補題として用意する（Mathlib 資産を流用するため）。
2. stratification の開集合版と閉集合版の同値性を中間補題として用意する（T2a の分解を助けるため）。
3. Defs の docstring で「要原典確認」とされている 4 点は、上記のとおりいずれも原典と同値と判断する。
   ただし最終確認は原典を手元に置いた人間が行うこと。
