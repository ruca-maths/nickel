## 結論
**仕様の欠陥は見つからなかった。** 各定義は Ceder (1961)、Borges (1966)、Gruenhage のハンドブックの定義と一致するか、
同値な形になっている。Tinf は意図どおり「任意の M₃ 空間は M₁ か」を表しており、肯定側・否定側のどちらにも自明な抜け道はない。

## 1. カーネルで確認済みの事実が与える裏付け（今回の新しい観点）
STATUS によると T1a〜T3 はすべて Checked になっている。これにより、定義について次のことが Lean で保証される。
* **自明でない。** T2d（距離化可能 ⇒ M₁）と T1b・T1c から、距離化可能空間は M₁・M₂・M₃ のすべてを満たす。
  したがって、どの M_i も「空の性質」になっていない。
  逆に、もし `IsM1` が全空間で真になるほど弱ければ、T2b から「すべての T3 空間がパラコンパクト」が導かれてしまう
  （M₁ ⇒ M₃ ⇒ stratifiable ⇒ パラコンパクト）。正則だがパラコンパクトでない空間（たとえば ω₁）が存在するので、
  これは偽であり、`IsM1` はそこまで弱くない。
  なお、この反例は Lean では未形式化で、紙の上での推論である。
* **同値な言い換え。** T2a と T3 から、Lean 上で
  `Tinf ⇔ (∀ X, IsStratifiable X → IsM1 X) ⇔ (∀ X, IsM2 X → IsM1 X)` が成り立つ。
  これは文献での問題の述べ方（「stratifiable ⇒ M₁ か」「M₂ ⇒ M₁ か」）と一致する。
  定義側で問題がすり替わっていないことの強い傍証になる。

## 2. 定義ごとの照合
| 定義 | 原典 | 判定 |
|---|---|---|
| `ClosurePreserving` | Ceder：任意の部分族 𝓖 について cl ⋃𝓖 = ⋃ cl G | 一致（有限部分族版ではない） |
| `SigmaClosurePreserving` | 可算個の CP 族の和 | 一致（有限和も、空族を並べれば表せる） |
| `IsQuasiBase` | x ∈ U 開 ⇒ ∃B, x ∈ int B ⊆ B ⊆ U | 一致 |
| `IsPairBase` | P₁ 開、P₁ ⊆ P₂、x ∈ P₁ ⊆ P₂ ⊆ U | 一致（P₂ は開でも閉でもなくてよい。Ceder どおり） |
| `Cushioned` | 任意の部分族 𝓠 について cl ⋃P₁ ⊆ ⋃P₂ | 一致 |
| `IsStratification` | Gruenhage 形（閉集合版） | 同値（単調減少性を課していないが、有限交叉で取り直せる） |
| `IsM1/2/3` | 正則 T₁ ＋ 各構造 | 一致（`T3Space` は T₀ と正則を合わせたもので、正則と T₀ から T₁ が出る） |
| `IsStratifiable` | T₁ ＋ stratification | 一致（正則性は stratification から導かれる） |
| `IsPerfectlyNormal` | 正規 ＋ 閉集合は Gδ | Mathlib の `NormalSpace` は T₁ を含まないが、T2c では仮定に T₁ があるので影響しない |

補足の確認:
* `IsTopologicalBasis` は「`𝓑` が生成する位相が元の位相に等しい」ことを要求する。
  したがって `𝓑` の元はすべて開集合で、`𝓑` は通常の意味の開基になる。空間が空なら `𝓑 = ∅` が開基として許されるが、これは正しい挙動である。
* `Set (Set X × Set X)` で対を表しているので、同じ P₁ に異なる P₂ を対応させることもできる。Ceder の「対の族」と同じ自由度である。
* `Cushioned` で 𝓠 = ∅ のときは `closure ∅ ⊆ ∅` となり真。`ClosurePreserving` で 𝓖 = ∅ のときも真。空族による穴はない。
* `IsStratification` の条件はすべて閉集合 H, K に限っている。非閉集合での G の値は自由になるが、どの主張にも影響しない。

## 3. 目標命題・量化・宇宙
* 各 Goal は `∀ (X : Type) [TopologicalSpace X], …` の形。量化の向きは正しく、インスタンス引数も一つなので位相の衝突はない。
* Tinf の否定は `∃ X : Type, ∃ 位相, IsM3 X ∧ ¬ IsM1 X` で、「M₃ だが M₁ でない空間」を正しく表している。
* 宇宙を 0 に制限しても、具体的に構成される反例（Chen–Wang 型の空間など、濃度は高々 2^𝔠 程度）はすべて `Type` に入る。
  したがって実質的な制限にはならない。
