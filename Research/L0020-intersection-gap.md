# L0020 調査メモ：開近傍との交差で CP 性は保たれない

**状態：L0020 の証明で使われる一般推論に反例。プレプリント全体の反証ではない。**

## GitHub 上の優先項目

現在の依存グラフでは、L0020 は「stratifiable だが、ある点が closure-preserving (CP) 外基を持たない空間」の構成であり、否定帰着 R0005 の中心にある。[L0020 の仕様](https://github.com/ruca-maths/nickel/blob/main/Specs/L_0020.lean) はこの反例を要求する。

Chen–Wang の [2018年 arXiv プレプリント](https://arxiv.org/html/1809.03763v2) は Theorem 1.b で stratifiable 非 M1 空間を主張する。その証明末尾（§9）は、σ-CP 基 `𝓑 = ⋃ᵢ 𝓑ᵢ` から、固定した点 `y` について

\[
  \mathcal B(i,y)=\{B\cap g(i,y): y\in B\in\mathcal B_i\}
\]

を作り、これが CP 外基になると述べる。ここで `g(i,y)` は `y` の開近傍である。以下の例は、CP 性と `y ∈ B` だけからこの交差後の CP 性を結論することはできない、と示す。

## 具体的反例

実数直線 `ℝ` に通常の位相を入れ、各 `n ≥ 1` に対して

\[
  F_n=\{0,2,1/n\},\qquad \mathcal F=\{F_n:n\ge 1\}
\]

とする。

**`𝓕` は CP である。** 空でない任意の `I ⊆ ℕ_{>0}` に対して、

\[
  \bigcup_{n\in I}F_n=\{0,2\}\cup\{1/n:n\in I\}
\]

は閉である。唯一あり得る集積点 `0` はすでに含まれる。また各 `F_n` は閉なので、任意の部分族で「和の閉包」と「各元の閉包の和」が一致する。

一方、`G=ℝ\setminus\{0\}` は `y=2` を含む開近傍であり、全ての `F_n` は `y` を含む。しかし

\[
  F_n\cap G=\{2,1/n\}
\]

の族は CP でない。全ての `n` を選んだ和 `\{2\}\cup\{1/n:n\ge1\}` の閉包は `0` を含むが、各 `F_n\cap G` は有限閉集合なので、その閉包の和は `0` を含まない。

従って、**CP 族であること、各 `B` が `y` を含むこと、交差相手が `y` の開近傍であることだけでは、`{B ∩ G}` の CP 性は保証されない。**

## より強い例：σ-CP 開基と stratification 条件も満たす

上の現象は、開集合族・基層CP・σ-CP基という設定でも起きる。実際、\(\mathbb R^2\) の可算開基を \(U_1,U_2,\ldots\) とし、\(\mathcal B_0=\mathcal F\)、\(\mathcal B_m=\{U_m\}\) (\(m\ge1\)) と置けば、各層はCPで、全体は開基である。\(\mathcal F\) がそのCP層の一つになる。

さらに L0014 の g-関数条件を満たす族を構成できる。\(g(0,z)=G\) (\(z=y\))、\(g(0,z)=\mathbb R^2\) (\(z\ne y\)) とし、\(n\ge1\) では
\[
g(n,z)=
\begin{cases}
G\cap B(z,1/n),&z=y,\\
B(z,1/n),&z\ne y.
\end{cases}
\]
とする。各 \(g(n,z)\) は開近傍で、\(n\) に関して減少する。任意の閉集合 \(K\) と \(x\notin K\) について、\(x\) は \(K\) から正の距離を持つため、十分大きい \(n\) では全ての \(g(n,z)\) (\(z\in K\)) が \(x\) から一様に離れ、分離条件も成立する。従ってこの g はプロジェクトの [L0014 の形式条件](https://github.com/ruca-maths/nickel/blob/main/Specs/L_0014.lean) を満たす。

しかし \(g(0,y)=G\) なので、\(\mathcal B(0,y)\) は上で CP でないと示した \(\{H\cup A_n:n\ge1\}\) そのもの。このため、σ-CP 基と通常の stratification g-関数という一般仮定から、交差族 \(\mathcal B(i,y)\) のCP性を導くことはできない。

これは特定の Chen–Wang 空間の証明を反証しない。特定の g と基の組が追加条件を満たしてこの例を排除する可能性は残る。


## 意味と次の確認
これはプレプリントの反例空間や Theorem 1.b 全体を否定しない。L0020 を根拠づけるには、原論文の `𝓑ᵢ` と `g(i,y)` が持つ追加構造から CP 性を導く別の議論があるかを確認する必要がある。追加条件が見つからなければ、Theorem 1.b のこの箇所は未解決の証明ギャップとして扱う。

次は、(1) 論文の基 `𝓑ᵢ` にこの反例を排除する条件があるか、(2) 定義 `HasCPOuterBase` と論文の「outer base」の形式化が一致しているか、を照合する。現時点では L0020 を Checked にせず、否定分岐の検証優先課題とする。
